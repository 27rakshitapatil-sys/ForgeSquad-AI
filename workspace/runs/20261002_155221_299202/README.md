# Python Calculator Application

## Overview
A simple command-line calculator that supports addition, subtraction, multiplication, and division.

## Structure
- `src/calculator.py`: Core logic for arithmetic operations.
- `src/main.py`: CLI interface.
- `tests/test_calculator.py`: Test suite using `pytest`.

## How to Run
1. Ensure you have `pytest` installed:
   ```bash
   pip install pytest
   ```
2. Run the application:
   ```bash
   python3 -m src.main
   ```
3. Run the tests:
   ```bash
   pytest tests/test_calculator.py
   ```
